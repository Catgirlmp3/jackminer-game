# JackMiner

**JackMiner is a Windows desktop blackjack game with an optional, explicitly controlled CPU-mining workload.** It is a beta project. The bankroll is virtual and has no cash value.

## Project goals

- A polished, self-contained Windows desktop experience.
- Blackjack with a €1,000 virtual starting bankroll and €300 maximum hand wager.
- Chips: €5, €10, €25, €50, €75, €100 and €200.
- Dealer stands on soft 17; blackjack pays 3:2; double down and split are supported; insurance is intentionally omitted.
- A configurable house edge, disclosed in the beta settings and implemented in the game rules rather than by secretly changing cards.
- Mining workload is optional, visible, bounded and controlled by JackMiner. It must never install or register a separate XMRig Windows service.
- UAC elevation is requested only when a user chooses a feature that genuinely requires it.
- Clean install, launch, stop and uninstall flows. No hidden persistence, process hiding or security-control tampering.

## Windows launcher

The planned entry point is `JackMiner.vbs`, a small launcher for the packaged desktop application. The application itself owns its UI, game state, settings, logs and optional workload lifecycle. Runtime files live under the user's local application data directory rather than being scattered beside the launcher.

## Security and Defender

JackMiner must not silently disable Microsoft Defender, tamper with security settings, or add broad antivirus exclusions. A mining executable may be flagged by security software; the beta should explain this plainly and provide verifiable publisher/hash information. Users can make their own informed decision in Windows Security.

## Build

The Windows desktop client is built with the .NET SDK. See the solution and project files for the exact target framework and publish profile.

## Beta status

This is experimental software. The mining component is opt-in and must be stopped cleanly when the game exits. The game remains playable with mining disabled. Do not run the beta on a machine where its resource use would disrupt other work.

## Fairness

Blackjack outcomes are generated by a documented shuffle and draw algorithm. House advantage comes from standard blackjack rules and configurable payout/rule choices—not fabricated cards, outcome overrides, or secretly rigged draws.
